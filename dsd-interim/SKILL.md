# dsd-interim - 분 · 반기 DSD 작성

**반복은 코드, 해석은 Claude, 결정은 사람.** 기간 넘기기 · 숫자 채우기 · 대사 · 검산은
[dsdxlsx](https://github.com/procpalee/dsdxlsx) 가 매번 같게 하고, Claude 는 바뀌는 문단 초안과
'못 채움' · '확인 필요' 정리를 돕고, 머리글 · 표시 기준(행 추가 · 삭제 · 라벨) · 최종 숫자는 사람이 정한다.

## 준비
- 파이썬 3.11+, [uv](https://docs.astral.sh/uv/)
- dsdxlsx 설치: `uv tool install git+https://github.com/procpalee/dsdxlsx` (명령 `dsdxlsx` 가 PATH 에 생김).
  저장소를 clone 해서 쓰면 환경변수 `DSDXLSX_HOME` 에 그 폴더를 넣는다.
- 한 번에 돌리는 스크립트: 이 스킬의 `scripts/interim.py`.

## 갈래
| 건 | 할 일 |
|---|---|
| 내가 DSD 를 작성 | 아래 1~4 전부 |
| 회사가 작성 · 내가 검토 | 3 의 대사 · 검산만 (`dsdxlsx recon` · `dsdxlsx check`) |

## 1. 원자료 고르기
- **뼈대** = 직전 중간보고서의 **최종** DSD(3분기 작업 → 반기 최종, 반기 → 1분기, 1분기 → 전년 3분기). 지난번에 고친 표 구조 · 문구가 그대로 살아난다.
- **전년 동기** = 작년 같은 분기 DSD - 손익 · 현금흐름 · 흐름형 주석의 전기 값.
- **전기 감사보고서 DSD** = 3분기 → 다음 해 1분기처럼 해가 바뀔 때만 - 전기말 값.
- **조서** = 당기 값이 있는 엑셀(분석적검토 조서 · 정산표 · 연결정산표). 엑셀에서 열어 저장한 파일이어야 수식 결과가 들어 있다.
- **건별 설정(선택)** = JSON 하나(대사 · 채우기 공용). 조서 시트 지정, 일부러 빼는 칸, DSD 와 이름이 다른 조서 행을 적는다 - 형식은 dsdxlsx README 1-1c(DSD ↔ 조서 대사).

## 2. 한 번에 돌리기
```bash
python ~/.claude/skills/dsd-interim/scripts/interim.py --base "<직전 최종.dsd>" --prior-same "<전년 동기.dsd>" \
    --workpaper "<조서.xlsx>" [--config "<설정.json>"] [--prior-annual "<전기 감사보고서.dsd>"] \
    --out-dir "<결과 폴더>" --name "<결과 이름>"
```
| 단계 | 결과 파일 | 볼 것 |
|---|---|---|
| 밀기(roll-interim) | `_당전기밀기.dsd` · `.xlsx` | '롤포워드' 시트의 확인필요 |
| 채우기(fill) | `_채움.dsd` · `_채움_채움결과.xlsx` | '못 채움' - 조서에 없는 값 · 후보 여럿 · 전기 값 다름 |
| 대사(recon) | `_채움_조서대사.xlsx` | 확인 필요 0 이거나 이유가 설명될 것 |
| 검산(check) | `_채움_검증.xlsx` | 합계 · 재무제표 ↔ 주석 · 표기 - 이상 없음이 목표 |

- 밀기: 기간 말 · 날짜 · 기수 치환('일반기업회계기준' 같은 낱말은 치환하지 않음), 당기 칸 비움, 전기 칸 ← 전년 동기, 전년 동기에만 있는 세부 행 삽입.
- 채우기: 같은 이름 행 × 당기 열, **전기 값이 맞는 행만** 채운다(전기 값으로 행 · 단위 · 부호를 확인). 합계 행은 위 칸으로 계산, 손익 결과 행에 이익 · 손실이 섞이면 라벨을 '…이익(손실)'로.

## 3. 사람 + Claude 가 정리
1. `_채움_채움결과.xlsx` '못 채움'과 대사 '확인 필요'를 목록으로 사용자에게 보여 주고, 값은 사람이 정한다. 조서에 값이 있는데 못 찾은 것이면 설정 JSON 의 '이름 다른 행'에 적고 다시 돌린다.
2. 바뀌는 문단만 Claude 가 초안(근거와 함께): 주주 구성 · 계속기업 · 후속사건 · 우발 · 특수관계자 서술. 숫자 표 머리글 · 표시 기준은 사람이.
3. 숫자를 DSD 에 손으로 적지 않는다 - 조서를 고치고 다시 돌리거나, DART 편집기에서 고친 뒤 `dsdxlsx check` · `dsdxlsx recon` 을 다시.

## 4. 마무리
- DART 편집기에서 `_채움.dsd` 를 열어 표 모양 · 쪽 나눔을 보고 저장 → 다시 `dsdxlsx check`.
- 오타 · 띄어쓰기 · 주석 번호 검토는 dsdxlsx 저장소의 `skills/dsd-review` 스킬.
- 결과 송부 메일이 필요하면 초안까지만(발송은 사람).

## 주의
- 원본 DSD · 조서는 고치지 않는다(결과는 새 파일). 결과 파일이 이미 있으면 덮어쓰기 전에 사용자에게 묻는다.
- 고객 DSD · 조서는 내 PC 에서만 다룬다. 외부 서비스 · 공개 저장소에 올리지 않는다.
