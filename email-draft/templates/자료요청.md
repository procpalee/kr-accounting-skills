# 자료요청 (PBC) 골격

제목: `[회사명] {감사/용역명} — 자료 요청의 건`

1. 인사 — 안녕하세요, {수신자} 님. 이재현입니다.
2. 배경 — {감사/용역명} 진행을 위해 아래 자료를 요청드립니다.
3. 요청 자료 목록 → `table(["No", "자료명", "기준일/기간", "형식"], rows)`
   - 항목이 3개 이하면 표 대신 `bullets`
4. 기한·방법 — "{날짜}까지 회신 부탁드립니다. 파일이 크면 {방법} 이용 부탁드립니다."
5. 맺음 — 확인 필요하신 사항은 편하게 연락 주세요. / 감사합니다.
