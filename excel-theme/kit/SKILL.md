# excel-theme

엑셀 산출물의 서식을 매번 새로 고르지 않고, 이 스킬의 규칙과 스크립트로 똑같이 맞춘다.
테마는 `default` 하나다(정산표·결산용 회색 표). 색·글꼴·표 규칙의 **단일 출처는 `scripts/excel_theme.py` 상단 편집 영역(`PALETTES`)** 이고,
`scripts/theme.json` 과 `references/themes.md` 는 거기서 자동으로 만들어진 사본이다(`scripts/sync_theme.py`).

## 1. 지금 어느 환경인지 먼저 정한다

| 환경 | 하는 일 | 읽을 문서 |
|---|---|---|
| **클로드 앱(claude.ai) · 클로드 코드** - 파이썬으로 .xlsx 파일을 만들거나 고친다 | `scripts/excel_theme.py` 의 openpyxl 헬퍼(`write_table` 등) 호출 | `references/openpyxl.md` |
| **클로드 엑셀** - 지금 열려 있는 통합문서를 직접 서식한다 | Office.js 로 서식 | `references/officejs.md` |
| **이 스킬을 회사 서식으로 바꿔 달라는 요청** | 편집 영역 수정 → 동기화 → 검증 → 새 스킬로 묶기 | `references/customize.md` |

스킬 폴더 위치: 클로드 앱 `/mnt/skills/user/excel-theme/` · 클로드 코드 `~/.claude/skills/excel-theme/`.
스크립트는 그 아래 `scripts/` 에 있다. 파이썬 표준 라이브러리 + openpyxl 만 쓴다.
색 값은 `references/themes.md`, 테두리·합계행·정렬 규칙은 `references/rules.md`.

## 2. 어느 환경에서나 지키는 규칙

- **계산값은 수식으로.** 합계·소계·차이·비율·건수는 SUM/SUMIFS/COUNTIFS/ROUND 같은 엑셀 수식으로 넣는다.
  파이썬이나 머릿속에서 계산한 숫자를 값으로 넣지 않는다. 값은 원자료·판단 파라미터·텍스트뿐이다.
- **배치 규약.** A열과 1행은 비우고 표는 B열부터. B2 제목 밴드 → 4행 헤더.
- **제목 밴드에는 시트명만.** 회사명·기준일·설명을 붙이지 않는다. 설명은 캡션이나 비고 열에.
- **캡션은 짧은 명사구(40자 이내).** 캡션 바로 아래 한 줄을 비우고 그다음 행이 헤더.
- **긴 대시(— – ―) 대신 하이픈(-).** 가운뎃점(·)은 써도 된다.
- **행높이·틀고정은 건드리지 않는다.** 긴 문장은 줄바꿈·열너비(최대 30자)·병합으로.
- **색은 테마 토큰만.** 임의 색을 새로 만들지 않는다. 시트 탭 색은 역할(`guide`·`output`·`calc`·`input`·`pbc`·`raw`)로만.
- **기존 파일·표를 고칠 때는** 사용자가 말한 범위만 서식하고, 실행 전에 대상 범위를 알린다.
- **스크립트가 낸 서식 코드는 고치지 않는다.** 실패하면 오류를 그대로 알린다(고칠 곳은 스크립트다).
