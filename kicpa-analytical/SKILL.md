# kicpa-analytical - 2120A · 8110A 분석적절차(한공회 표준조서)

공통 코드는 `~/.claude/skills/kicpa-jet/kicpa_core`(분개장 · TB 읽기, 과목 골격 `frameworks.py`).

## 도구
| 도구 | 하는 일 |
|---|---|
| `ar_build.py prepare` | 과목 계산 + AI 초안 근거 → `<조서>_work\analysis.md · analysis.json` |
| `ar_build.py build` | 조서 생성(`--notes` 를 주면 설명 칸에 초안) + `_work\summary.json` |
| `ar_check.py` | LibreOffice 재계산으로 과목 금액 · 잠정 판정 · 검증 줄이 파이썬과 같은지 대조 |

```
python -X utf8 ar_build.py prepare|build --stage 계획|기말 --gaap ifrs|kgaap --company <회사명> --year-end 2026.12.31
      (--tb <xlsx|csv> | --tb-dir <xlaudit tb 폴더> --tb-date 2026.09.30 --tb-prior-date 2025.12.31 | --tb-json <json>)
      [--journal <분개장 파일 · 폴더>] [--pm 금액] [--ratio 0.1] [--annualize O|X] [--author 이름] [--notes notes.json] --out <xlsx>
python -X utf8 ar_check.py <조서.xlsx>
```
- 계획(2120A): 기준일 TB vs 전기말. 기준일이 연중이고 비교가 전기 연간이면 손익을 연환산(기초정보에서 O/X).
- 기말(8110A): 당기말 vs 전기말. 분 · 반기 검토 8110 에도 쓸 수 있다(전년 동기 TB 를 --tb-prior 로 주면 연환산 X).
- 판단기준 금액 = 수행중요성(2700, `--pm`), 비율 기본 10%. 없으면 임시값 + 경고.

## AI 초안 (이 대화의 Claude 가 쓴다)
1. `prepare` → `analysis.md` 를 읽는다(잠정 O · △ 과목마다 TB 계정 증감, 분개장이 있으면 상대계정 · 거래처 · 큰 전표).
2. `notes.json` = `{"설명": {"BS:매출채권": "문장", "IS:매출액": "문장"}}` - 개조식 1~3줄, 끝 마침표 없음, 자료로 확인한 사실만.
   원인을 모르면 '… 확인'으로 끝낸다. 결론 · 최종 O/X 는 쓰지 않는다(사람). `stop-slop-ko` 규칙, 조서 만든 뒤 `slop_scan.py` WARN 0.
3. `build --notes notes.json`. 초안 칸은 흰 칸(사람이 고쳐 씀).

## 조서 구조 (excel-theme `audit`)
| 시트 | 내용 | 사람 칸 |
|---|---|---|
| 기초정보 | 조서 목적 · 기본 정보(기준일 · 경과 월수 · 연환산 · 이익잉여금에 당기순이익 더함) · 판단 기준(수행중요성 · 금액 · 비율) - 이름 정의 원본 | 연환산 · 가산 · 판단 기준 |
| 2120A · 8110A | 한공회 표: 과목 · 당기 금액 · 백분율 · 전기 금액 · 백분율 · 증감 · 증감률 · 유의적 차이(잠정 = 수식 / 최종) · 설명 또는 감사계획에 반영할 사항(K:L 병합) · [8110A: 계획단계 식별 사항 해소] · 관련 조서번호 → 검증 4줄 → 결론 | 최종 · 설명 · 해소 · 관련 조서 · 결론 |
| -1 재무비율 | 안정성 · 수익성 · 활동성 · 성장성 19개(IFRS 는 리스부채 포함 차입금 · 순차입금) | 해설 |
| -2 월별 추세 | (분개장이 있을 때) 월별 매출 · 매출원가 · 원가율 | 해설 |
| Data_TB · Data_과목 · [Data_분개장] | TB(과목키 드롭다운 = 매핑) · 과목 목록 · 매출 · 매출원가 분개 | Data_TB 과목키 |

- 잠정 판정 = 증감 ≥ 금액 기준 그리고(전기 0 이거나 증감률 ≥ 비율 기준) → O, 둘 중 하나 → △, 아니면 X. 증감 = 당기 - 전기(한공회 원본은 2120A 가 전기 - 당기로 섞여 있어 통일).
- 매핑: 표시과목(TB 에 있으면) → 계정과목 순으로 정규식, 묶음 표시과목('매출채권및기타채권')은 계정명으로만, 안 맞으면 더존 3자리 분류 번호 기본값. '기본값 배정' 경고는 확인해 둔다.
- TB 가 손익을 따로 두면(재무상태표 합 ≠ 0) 이익잉여금 줄에 당기순이익을 더한다(자동 판정, 기초정보에서 고침). 순이익 = 손익 계정만(제조원가 계정은 매출원가에 이미 들어 있음).

## 넘기기 전
`ar_check.py` '모두 일치' → `theme_lint.py <조서> audit` · `render_check.py` 위반 0(행높이는 build 가 엑셀 COM 으로 맞춤, `--no-fit` 이면 `kicpa_core.wp.fit_rows`) → `slop_scan.py` → `excel-sync` 기준본.
고객사명 · 실데이터는 스킬 폴더에 두지 않는다.
