# kicpa-sap - 3300A 실증적 분석절차(한공회 표준조서)

판단(대상 · 주장 · 정밀도 · 외부 파라미터 고르기 · 수용가능한 차이 · 차이 조사)은 아래 9단계(기준서 520 문단 5 · 7)를 따른다.
이 스킬은 그 결과를 한공회 3300A 서식으로 남기는 빌더다. 공통 코드는 `~/.claude/skills/kicpa-jet/kicpa_core`.

## 9단계 (판단은 사람과 함께 정한다)
| 단계 | 할 일 |
|---|---|
| 1. 대상 · 주장 · 기간 | 계정과 경영진 주장(발생사실 · 완전성 · 정확성 등)을 정하고 모집단 금액을 TB 와 대사. 일부만 대상이면 제외 범위와 대체 절차를 적는다 |
| 2. 정밀도 요인 | 예측가능성 · 분리가능성(제품 · 월 · 채널 · 사업장) · 자료 신뢰성 · 절차 유형. 부정위험 계정(매출)은 세부테스트 결합 계획을 적는다 |
| 3. 기대치 모델 | 드라이버 × 파라미터. 핵심 파라미터는 회사 밖 숫자(공표 통계 · 시장가격 · 계약 · 법정 요율)를 우선. 합산 항목은 실제 수량 비중으로 안분 |
| 4. 자료 신뢰성 | 드라이버를 독립 자료(수불부 · GL · 외부 증빙)와 대사. 파라미터는 출처 · 조회조건 · 조회일 · 화면 캡처. 단위 · 부가세 포함 여부 · 평균 방식 확인 |
| 5. 수용가능한 차이 | 수행중요성(2700)에서 출발. SAP 만으로 대응하면 PM 이하. 셀 단위(월별) 기준은 두지 않는다 |
| 6. 비교 | 차이 = 실제 - 기대치. 총차이 절대값 ≤ 수용가능한 차이면 추가 절차 불요 |
| 7. 차이 조사 | 초과 시 경영진 질문 → 답을 뒷받침하는 추가 증거(질문만으로 끝내지 않음) → 모델 결함인지 회사 기록 문제인지 구분 |
| 8. 수정 후 재비교 | 모델 결함이 확인되면 기대치를 고쳐 다시 비교, 아니면 N/A |
| 9. 결론 | 주장별 결론과 기말 · 후속 절차 |

자주 걸리는 것: 도매 · 소매가 섞인 매출에 소매 평균가 전량 적용(채널을 나누거나 범위를 한정), 공표 가격의 부가세 포함 여부 · 단위(드럼 200ℓ 등) · 산술평균과 물량가중 차이, 회사 진술을 데이터 없이 받아들이기.

## 도구
```
python -X utf8 sap_build.py <input.json> [--out <xlsx>] [--overwrite] [--no-fit]
python -X utf8 sap_check.py <3300A.xlsx> [--expect <기대치> <차이>]      # 재계산 대조(기존 조서 값과도)
```
- 입력 스키마 = `examples/sap_input_example.json`(가상 회사 - 임대수익 = 면적 × 계약 단가, 이자수익 = 평균잔액 × 금리 ÷ 12, 대상 2개).
- 드라이버: `raw`(원자료 열) · `factor`(환산계수, 예 드럼 → 200ℓ) · `share`(합산 수량을 비중으로 나눌 때, 예 휘발유 → 고급 · 보통) · `map`(항목마다 원자료 열 · 비중 열).
- 파라미터: `rows`(기간 × 항목) · `divisor`(VAT 1.1, 월 환산 12 등) · `source_lines` · `captures`(조회화면 그림 경로 - 있으면 B 시트에 넣음).
- 고객 실데이터 입력 JSON 은 조서 폴더에 둔다(스킬 폴더 금지). 조서번호는 `wp_no`(계정 조서에 둘 때 예: 6000B).

## 조서 구조 (excel-theme `audit`)
| 시트 | 내용 | 사람 칸 |
|---|---|---|
| 3300A | 기본 정보(수행중요성 이름 원본) · 요약표(대상마다 한 줄, Ref 링크, 기대치 · 수용가능한 차이 · 차이 · 판정은 Ref 시트 수식) · 결론 | 수행중요성 · 결론 |
| Ref.n <대상> | 1 대상 · 주장 · 범위(TB 대사) · 2 정밀도 요인 · 3 기대치 모델 · 4 자료 신뢰성 · 5 수용가능한 차이 · 6 기대치와 실제 비교 · 판정 · 7 차이 조사 · 8 수정 후 재비교 · 9 결론 | 판단 문장 · 실제 금액 · 결과 · 결론 |
| Ref.n-A 드라이버 · Ref.n-B 파라미터 | 원자료(크림) · 환산계수 · 안분 비중 · 산출 드라이버(수식) / 외부 자료 · 나눔 계수 · 적용 단가(수식) · 출처 | 원자료 · 파라미터 |

- 셀 단위(월별) 판정 기준은 두지 않는다 - 총차이 절대값 ≤ 수용가능한 차이(PM × 비율)로만 판정, 기간별 표는 정보.
