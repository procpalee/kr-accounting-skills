# 문서별 문체와 건드리지 않는 것

문체를 고친다는 것은 문장부호, 번역투, 상투구, 구호를 고친다는 뜻이다. 종결어미와 내용은 고치는 대상이 아니다.

## 종결어미는 저자가 고른 문체다

| 자리 | 흔한 종결 | 예 |
|---|---|---|
| 소제목, 표 머리, 라벨 | 명사 종결 | 매출채권 연령 분석, 대손충당금 설정 |
| 조서 서술 칸, 주석, 검토 의견 | `~함`, `~임`, `~됨` | 전기 대비 12% 증가함, 회수 가능하다고 판단됨 |
| 업무 메일, 안내문, 제안서 | `~합니다`, `~드립니다` | 아래 자료를 요청드립니다 |
| 기고문, 칼럼, 블로그 | `~다` 또는 `~습니다`(글마다 하나) | |

- 다듬을 때 종결어미를 바꾸지 않는다. `~함`을 `~한다`로, `~습니다`를 `~다`로 바꾸지 않고 그 반대도 하지 않는다.
- "본문인데 `~함`이 어색하다", "능동으로 쓰면 더 자연스럽다", "명사 종결이 밋밋하다"는 생각이 들면 멈춘다. 영어 글쓰기 규칙(능동태, 짧은 문장)을 한국어 개조식에 옮기면 오히려 어색해진다. 밋밋한 것은 고칠 이유가 아니다.
- 한 문서에 종결이 섞여 있으면 고치지 말고 섞여 있다고 알린다. 통일은 톤 맞춤에서 기준 문서를 정했을 때만 한다(`tone-extraction.md`).
- 기존 문서에 내용을 덧붙일 때는 그 문서의 종결을 따른다.

## 반드시 보존하는 것

- 숫자와 단위(금액, 건수, 비율, 날짜), 계정과목, 조서번호, 문단 번호, 쪽 번호
- 회사명, 사람 이름, 제품명, 기술 용어
- 인용문 원문, 법령 조문, 기준서 문장. `~에 대한`, `인식함`, `측정함`, `손상차손을 인식함` 같은 기준서 표현은 번역투로 보지 않는다
- 당위(`~해야 함`), 추측(`~로 보임`), 가능(`~할 수 있음`). 단정으로 바꾸면 뜻이 달라진다
- 붙여 쓴 가운뎃점 복합어(매출·매입, 성능·품질). 앞뒤에 공백을 둔 가운뎃점 나열만 고친다
- 표에서 해당 없음을 뜻하는 `-`, `—` 칸과 흐름을 나타내는 `→`
- `※` 주석 기호(너무 많을 때만 줄인다)

## 사실을 지어내지 않는다

- 구호나 교훈형 마무리를 고치려면 그 자리에 들어갈 사실이 있어야 한다. 원자료에 있으면 그것을 쓰고, 없으면 문장을 지우거나 `[확인 필요: ...]`로 두고 작성자에게 묻는다.
- 회의록에 발언에 없는 결정, 일정, 담당자를 넣지 않는다. 없으면 "미정"이다.
- 구호를 그럴듯한 다른 구호로 바꾸는 것은 고친 것이 아니다.

## 대상이 아닌 글

- 다른 사람이 보지 않는 글: 숨김 시트, 내부 점검 파일, 스킬 문서, 프롬프트, AI 지침
- 사용자가 "원문 그대로", "문구 그대로"라고 한 글
- 영어 글, 코드
