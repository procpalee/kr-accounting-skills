# ledger-merge — 계정별원장 통합

합치는 일은 매번 같아야 하므로 **항상 `scripts/merge_ledger.py`로 한다**(즉석 코드 금지).

## 실행
```bash
python ~/.claude/skills/ledger-merge/scripts/merge_ledger.py "<원장.xlsx>" [--out-dir <03_산출>] [--overwrite]
```
- 필요: 파이썬 3.11+ · openpyxl, 같은 스킬 폴더(`~/.claude/skills/`)에 `excel-theme` 스킬. 다른 곳에 설치했으면 경로를 그 스킬 폴더로 바꾼다.
- 입력 원장은 읽기만 한다(01_받은자료는 원본). 결과는 `03_산출/<원래 파일 이름>_통합.xlsx`.
  03_산출은 입력 파일의 상위 폴더에서 자동으로 찾고, 못 찾으면 `--out-dir`.
- 결과 파일이 이미 있으면 멈춘다. 사용자가 손댄 파일일 수 있으니 확인한 뒤에만 `--overwrite`.

## 결과 구조
- **통합** 시트: 계정코드 · 계정명 · 일자(YYYY-MM-DD) · 적요 · 거래처코드 · 거래처 · 차변 · 대변 · 잔액
  - [월계]·[누계] 줄 제외, 전기이월 줄은 유지(원장에 날짜가 없으므로 일자는 빈칸 — 지어내지 않음).
  - 연도는 원장 상단 기간(예: 2018.01.01 ~)에서 가져오고, 월이 줄어들면 다음 해로 본다.
- **확인** 시트: 계정별 통합 차변·대변 합계(SUMIFS 수식) vs 원장 마지막 [누계] 줄(원자료 값), 차이(수식), 결과(일치/불일치/확인 필요), 맨 아래 합계·전체 판정.
  - 원장 [누계]는 전기이월을 포함한 연누계라 통합 합계와 그대로 비교된다.
  - [누계] 줄이 없는 계정은 "확인 필요"로 표시한다.
- 서식은 스크립트가 `excel-theme`(기본 `default`)의 `apply_theme`로 입힌다. 다른 테마가 필요하면 스크립트 상단 `THEME` 변경.

## 끝낸 뒤
1. 스크립트가 출력하는 요약(계정 수·거래 줄 수·누계 대조 결과·주의 항목)을 사용자에게 그대로 전한다. 불일치·확인 필요는 숨기지 말고 계정코드까지 적는다.
2. 확인 시트의 수식 값은 엑셀에서 열어야 계산된다 — 스크립트의 대조 결과는 같은 계산을 파이썬으로 한 것임을 밝힌다.
3. 엑셀을 넘기기 전 `excel-sync` 스킬로 기준본을 남긴다.

## 형식이 다를 때
원장 머리글이 `날짜/적요란/코드/거래처/차변/대변/잔액`(공백 무시) 순서가 아니면 해당 시트는 건너뛰고 "확인 필요"로 알린다. 형식이 다른 원장은 스크립트를 먼저 고친 뒤 쓴다.
