# 메일 히스토리 문서 형식

거래처 폴더의 `메일 히스토리.md`. 원고에 `{#번호}` 로 근거를 달고 `mail_links.py` 로 원본 메일 링크를 만든다.
사람이 직접 고친 줄(상태·기한·메모)은 덮어쓰지 않는다.

```markdown
# <거래처> 메일 히스토리

- 작성 · 갱신: YYYY-MM-DD (메일 #1 ~ #N 반영)
- 출처: 거래처 폴더 메일 원본(메일\) - 번호를 누르면 Outlook 으로 열린다
- 한계: 전화 · 대면으로 오간 내용은 없다. 메일함에 남은 기간보다 오래된 메일은 없다

## 1. 사람과 역할
| 쪽 | 이름 | 직책 · 담당 | 주소 | 근거 |
|---|---|---|---|---|
| 거래처 | | | | [#3](<…>) |
| 외부 | | | | |
| 우리 | | | | |

## 2. 타임라인
| 날짜 | 일 | 근거 |
|---|---|---|

## 3. 확인 · 결정 사항
- 무엇을 누가 언제 정했는지 한 줄씩(근거 번호)

## 4. 챙길 것
| # | 할 일 | 출처 | 상태 | 기한 | 메모 |
|---|---|---|---|---|---|
| E1 | | [#12](<…>) | 미결 | | |

## 5. 주고받는 패턴
- 창구(누가 답하는지) · 답 속도 · 자주 늦는 것 · 선호(파일 형식 · 연락 방법)
```

- **4절이 핵심**이다. 약속, 답 없는 질문, 미룬 일, 만료되는 대용량 링크를 빠짐없이 올리고, 처리되면 상태만 바꾼다(지우지 않음). 번호는 E1, E2 … 이어 붙인다.
- 상태: 미결 / 회신 대기 / 상대 준비 / 요청 예정 / 완료 / 해당 없음(뒤에 '- 설명' 가능).
- 새 메일로 처리된 것 같으면 메모에 근거(#번호)를 적고 보고에 '완료 후보'로 올린다 - 완료로 바꾸는 것은 사람.
- 메일로 답이 안 보이는 요청은 바로 '미결'로 적지 말고 전화·대면으로 해결됐는지 사용자에게 묻는다.
- 자동 알림, 단순 전달처럼 반영할 것이 없는 메일은 건너뛰되 번호는 넘긴다.
