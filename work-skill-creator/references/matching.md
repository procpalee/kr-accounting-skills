# 3단계 - ①과 맞추기

목표: 코드로 다시 만든 파일과 ① 지난 기간 완성본의 차이를 0으로(또는 이유가 적힌 차이만 남게) 만든다.
지난 기간에 사람이 만든 파일이 맞춰 볼 기준이 되므로, 클로드가 맞게 했는지 스스로 확인할 수 있다.

## 1. 비교 돌리기

업무 스킬의 재현 시험이 기본이다(비교 도구를 대신 불러 준다):
```
python -X utf8 "<업무 스킬>/scripts/build.py" --period <지난 기간> --out 02_작업/재현_<지난 기간>.xlsx --apply --expect "<①>"
```
- `references/known_diffs.txt` 의 범위는 자동으로 빼고 비교한다. 비교 도구 옵션을 더 넘기려면 `--cmp "--formats --blank-zero"`.
- 비교 도구를 직접 돌릴 때:
```
python -X utf8 "<스킬>/scripts/compare_xlsx.py" "<만든 파일>" "<①>" [--formats] [--ignore-file known_diffs.txt] [--json 02_작업/차이.json]
python -X utf8 "<스킬>/scripts/compare_docs.py" "<만든 파일>" "<①>" [--numbers]     # 워드 · PPT
```
- 먼저 값 · 수식만 맞춘 뒤 `--formats` 로 서식(숫자 서식 · 채우기 · 테두리 · 열 너비 · 병합)까지 맞춘다. 행 높이와 메모는 비교하지 않는다(필요하면 눈으로).
- 차이가 많으면 시트 순서대로 나눠 맞춘다(`--sheets`): 원자료 시트 → 계산 시트 → 요약 · 분개.
  앞 시트의 차이가 뒤 시트로 번지므로 앞에서 고치면 뒤 차이가 한꺼번에 사라진다.
- "계산값이 없습니다" 경고가 나오면 만든 파일을 엑셀로 다시 계산하지 않은 것이다(`--recalc` 로 임시 확인 가능, 근본 해결은 build 에서 `W.excel_recalc`).
- 종류: `값` 계산 결과가 다름 · `수식` 수식 글자가 다름(값이 같다고 표시되면 덜 급함) · `값↔수식` 한쪽은 값, 한쪽은 수식 · `서식` · `시트`.
  **`값↔수식` 에서 '만든 쪽이 값'이면 값을 붙여 넣은 것이니 반드시 수식으로 고친다.**
  '완성본 쪽이 값'(사람이 친 값을 코드가 수식으로 바꿈)이고 값이 같으면 원칙대로 고친 것이다 → `--formula-ok` 로 따로 세거나 known_diffs 에 적는다.

## 2. 차이마다 원인 가르기

| 원인 | 예(실제 사례) | 처리 |
|---|---|---|
| 코드 잘못 | 수식 열이 한 칸 밀림 · ERP 보고서 제목 줄을 계정으로 읽음 · 상대 경로라 재계산이 빠져 683칸이 빈 값 · `Decimal` 나눗셈(`//`)이 0 쪽으로 버려 차트 축 최댓값이 다름 | 코드를 고친다 |
| 빠진 규칙 | 거래처코드 열이 글자 서식(앞자리 0 보존) · 지난 기간 노란 표시가 따라옴 · 명단이 늘 때 굵은 선이 한 줄 위로 · 표 틀 너비 · 한 표만 글자 크기가 다름 | 규칙을 코드에 넣고 SKILL.md 7절에 적는다 |
| 사람 판단 차이 | 개별평가 명단에 거래처 추가(비고에 '승인' 문구) · 계약 해지 여부 · 비리스요소 분리 | 판단 입력 파일로 받는다 ✋ - 코드 안 상수로 넣지 않는다 |
| 원칙 때문에 일부러 다르게 만든 것 | `Data_` 시트 추가 · 사람이 친 값을 수식으로 · 기간 문구를 기준일 수식으로 · '판단근거' 시트 | `known_diffs.txt` 에 범위 · 이유 · 영향을 적는다 - 재현 시험이 빼고 비교한다 |
| 완성본의 실수 | 세율 구간이 글자로 고정돼 산출세액 과소 · 옛 판 분개가 옮겨 적힌 채 남음 · 수식 범위가 한 열을 덜 덮음 · 반올림 잔여 1원 · 28원 | 맞추지 않는다 ✋ - 사용자에게 보여 주고 정한다 |
| 의미 없는 차이 | 빈칸 ↔ 0 · 소수점 끝자리 오차 · 메모 문구 표현 | `--blank-zero` · `--tol` 또는 known_diffs 로 두고 이유를 적는다 |

판단이 애매하면 사용자에게 차이 칸 · 두 값 · 짐작한 원인을 보여 주고 묻는다. "코드 잘못인지, 사람 판단 차이인지"를 먼저 가른다.

**완성본의 실수를 찾았을 때**
1. 근거(어느 칸 · 왜 틀렸는지 · 영향 금액)를 보여 준다.
2. 사용자가 정한다: (가) 이번에는 완성본에 맞추고 다음 기간부터 고친다 / (나) 스킬은 맞는 방법으로 만들고, 그 칸은 알려진 차이로 둔다.
3. (나)면 `known_diffs.txt` 에 "범위 | 완성본 실수 - 이유 | 영향 금액"으로 적는다.

## 3. known_diffs.txt

업무 스킬의 `references/known_diffs.txt` - 재현 시험이 다르게 봐도 되는 범위 목록. 한 줄에 하나, `|` 로 나눈다. `#` 으로 시작하면 설명 줄.
```
# 범위 | 이유 | 영향
Data_채권명세 | 원자료를 시트째 붙이는 원칙(완성본에는 없음) | 없음
값만:충당금계산!E38:E39 | 적요를 기준일 수식으로 바꿈(완성본은 손으로 친 글자) | 없음 - 값 같음
값만:분기말잔액!E5:F13 | 수식 속 기간 숫자(202606)를 기준 년월 칸 참조로 바꿈 | 없음 - 값 같음
서식만:이자율!B:B | 사람이 열 너비를 손으로 바꿈 | 없음
TB!J17 | 완성본 실수: 수식을 값으로 덮어씀(사용자 확인 2026-10-13) | -43,171,473
```
- 범위 모양: `시트!A1:C3` · `시트!F:F` · `시트!3:3` · `시트`(통째로 - 한쪽에만 있는 시트도 빠진다).
- 앞에 붙이는 말: 없으면 **통째로 뺀다**, `값만:` 은 **수식이 달라도 되고 값은 비교한다**(원칙대로 수식으로 바꾼 칸은 대부분 이것),
  `서식만:` 은 서식(열 너비 · 행 높이 · 채우기)만 뺀다. 값을 확인할 수 있는 칸을 통째로 빼지 않는다.
- 이유 없이 넣지 않는다. 판단 차이는 여기가 아니라 판단 입력 파일로 간다.

## 4. 하지 않는 것

- **①의 계산 결과를 옮겨 적어 맞추기.** 숫자가 맞아도 다음 기간에 틀린다. 프롬프트에 없더라도 지킨다.
- 판단을 코드 안 상수로 숨겨 맞추기(예: `if 거래처 == "거래처 A": 손실률 = 1`).
- 이유 없이 `--ignore` · `--tol` · known_diffs 로 차이를 감추기.
- 차이가 남았는데 "거의 같다"로 넘어가기. 남긴 차이는 하나씩 설명할 수 있어야 한다.

## 5. 글로 쓴 칸 · 문서

- 판단근거 · 비고 · 메모 같은 글 칸은 **결론이 같으면 된다**. 문장 차이는 known_diffs 로 빼고, 결론 · 금액 · 근거 문단 번호가 같은지 본다.
- 워드 · PPT 는 숫자 · 표 · 차트 값이 0 이 목표다. 문단 글자는 차이를 사람이 읽고 판단한다.
  `compare_docs.py --numbers` 에서 '숫자 한쪽에만'(금액이 빠지거나 틀림)을 먼저 본다. '숫자 횟수'는 문장 차이일 때가 많다.
- 그림 비교가 필요하면 쪽마다 PNG 로 내보내 넘침 · 겹침을 눈으로 본다(PPT · 워드는 프로그램으로 내보내기).

## 6. 기록

업무 스킬 SKILL.md 7절에 이렇게 적는다 - 다음에 같은 실수를 하지 않고, 스킬을 넘겨받은 사람이 왜 그렇게 짰는지 안다.
여러 사람이 쓰는 스킬이면 거래처명 대신 '거래처 A', 금액은 규모만 적는다.

```markdown
## 7. 맞추며 고친 것 (재현 기록)
처음 다시 만들었을 때 차이 468개 → 0개 (2026-06 완성본, 6시트 2,187칸).
1. 명단 추가(거래처 A) - 사람 판단 차이. 판단 입력이 없으면 집합평가로 남아 468칸 차이 → 판단 입력 '개별평가_추가' 로 받게 함.
2. 지난 기간 노란 표시가 따라옴 - 빠진 규칙. 연령분석 O열 채우기를 먼저 지우고 이번 기간 기준으로 다시 칠함.
3. 상대 경로 출력 시 재계산 실패 - 코드 잘못. 출력 경로를 절대 경로로.
```

## 7. 보고

맞추기가 끝나면 짧게 보고한다:
- 처음 차이 N개 → 0개(비교한 시트 · 칸 수)
- 고친 것(원인 종류별로 몇 개), 판단 입력으로 돌린 것, known_diffs 에 넣은 것, 완성본에서 찾은 실수
- 사용자가 확인할 것
